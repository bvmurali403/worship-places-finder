🛕 Worship Places Finder:

Discover. Explore. Learn.
A responsive web application for discovering and exploring worship places from different religions. The application provides an easy-to-use interface for searching worship places, filtering them by religion, viewing place information, checking facilities, detecting the user's location, managing favorites, viewing details, and exploring historical information.
The project is developed completely using HTML, CSS, and JavaScript and is deployed using GitHub Pages with GitHub Actions.

🏠 Project Overview:
Worship Places Finder is a frontend web application designed to help users discover worship places belonging to different religions.
The application provides a centralized interface where users can explore places such as:
Hindu Temples
Mosques
Churches
Gurdwaras
Buddhist Temples
Jain Temples
Synagogues
Zoroastrian Fire Temples
The application is designed with a commercial-style discovery experience inspired by modern platforms such as marketplace and location-discovery applications.
The main goal is to make worship-place discovery simple, organized, responsive, and visually appealing.

❗ Problem Statement:
Finding information about worship places often requires searching through multiple websites, maps, and individual sources.
Users may want to know:
Which worship places are nearby?
What religion does a place belong to?
What facilities are available?
What are the opening hours?
What is the rating?
How far away is the place?
What is the history of the place?
What architectural features does it have?

🎯 Project Objective:
The major objectives of the project are:
Build a responsive worship-place discovery website.
Support multiple religions.
Provide search functionality.
Provide religion-based filtering.
Display ratings and distances.
Provide detailed place information.
Provide facilities information.
Provide historical and architectural information.
Allow users to mark places as favorites.
Provide location detection.
Provide directions functionality.
Provide sharing functionality.
Provide image-based place presentation.
Provide a mobile-friendly interface.
Provide dark-mode support.
Provide user-friendly notifications.
Deploy the application publicly using GitHub Pages.
How can the user navigate to it?
The Worship Places Finder attempts to provide these types of information through one unified interface.
